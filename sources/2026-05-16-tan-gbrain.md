# What is GBrain?

**In one line:** Garry Tan describes his open-source GBrain as a layered knowledge system for personal agents and explicitly not "RAG in a box".

## What it says

- GBrain is an open-source project he presents as a knowledge system, not a packaged retrieval pipeline.
- It gives agents eight layers that work together to improve memory.
- The stated goal is personal AI: an agent such as OpenClaw or Hermes Agent that knows who you are.

## What to do with it

- Read it as a signal about direction: a large personal knowledge base grows extra layers on top of plain files, and its builder still does not describe the result as RAG.
- For detail on the layers, go to the project itself. This post does not list them.

## Caveats

- Only the text of the post was read. Any attached media or thread was not, hence `read: partial`.
- The brief that seeded this brain adds figures that could not be confirmed from the post: about 350,000 markdown files, SQLite with combined graph and vector search, and 17 "brain skills". Treat them as unverified until the project documentation is ingested.
