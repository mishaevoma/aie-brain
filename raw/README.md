# raw/

Local inbox for full-text captures: clipped articles, PDFs, transcripts, exported threads.

Everything here except this file is gitignored. The repo is public and these files are other people's copyrighted work, so they stay on your machine. What gets committed is the source note in `sources/`: our own summary plus a link to the original.

How to use it:

1. Drop a file here (the Obsidian Web Clipper works well), or just give the agent a URL.
2. Ask the agent to ingest it. It reads the file, writes the source note and updates the wiki.
3. Keep the file if you want the agent to be able to re-read the full text later. Agents treat files here as read-only.
