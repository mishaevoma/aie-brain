# Index

Read this first. It lists every page with one line on what it holds. "By decision" goes from a question to the pages that answer it. Concepts and playbooks are listed by hand. The source list at the bottom is generated by `python3 tools/lint.py --sync`.

## Start here

- [Overview](overview.md) — the stack, what the sources agree on, live debates, how the picture moved, known gaps.
- [Glossary](glossary.md) — the shared vocabulary, one line per term.

## By decision

Start from the question you are facing. Each line names the pages to read, the most useful first. Read those, not the whole wiki.

**Building an AI product**

- Where do I start? [Building an agent product](playbooks/building-an-agent-product.md).
- One model call, a workflow or an agent? [Agents and workflows](concepts/agents-and-workflows.md), then step 1 of [Building an agent product](playbooks/building-an-agent-product.md).
- Build a harness or adopt one? [Harness](concepts/harness.md), [Context layer](concepts/context-layer.md).
- What rides in every prompt, and what is loaded on demand? [Context engineering](concepts/context-engineering.md), [Retrieval](concepts/retrieval.md), [Skills](concepts/skills.md).
- RAG, search or a compiled wiki? [Retrieval](concepts/retrieval.md), [LLM wiki](concepts/llm-wiki.md).
- How many tools, and when to load them on demand? [Tool design](concepts/tool-design.md), [MCP](concepts/mcp.md).
- How do I connect an outside system? [MCP](concepts/mcp.md), [Tool design](concepts/tool-design.md).
- How can the agent act without a person approving each step? [Permissions, sandboxing and containment](concepts/sandboxing-and-permissions.md), [Human judgment and oversight](concepts/human-judgment.md).
- How do I know it works, before launch and after? [Evals](concepts/evals.md), [Trusting eval numbers](concepts/eval-validity.md), [Running agents in production](concepts/production-operations.md).
- Does a benchmark number mean anything? [Trusting eval numbers](concepts/eval-validity.md).
- Should it remember anything between sessions? [Memory](concepts/memory.md), [LLM wiki](concepts/llm-wiki.md).
- One agent or several? [Multi-agent systems](concepts/multi-agent-systems.md).
- A task that runs for hours, or waits for a person? [Long-running agents](concepts/long-running-agents.md), [Running agents in production](concepts/production-operations.md).

**Setting up coding agents in a repository**

- Where do I start? [Setting up a repository for coding agents](playbooks/setting-up-a-repo-for-coding-agents.md).
- What belongs in `AGENTS.md`, and what in a skill? [Instruction files](concepts/instruction-files.md), [Skills](concepts/skills.md), [Context layer](concepts/context-layer.md).
- How does the agent show that its work is done? [Verification](concepts/verification.md).
- The same correction keeps coming back. [Compounding](concepts/compounding.md).
- How do I review what agents produce, and how many can I run? [Reviewing agent work](playbooks/reviewing-agent-work.md), [Human judgment and oversight](concepts/human-judgment.md), [Multi-agent systems](concepts/multi-agent-systems.md).
- Which commands may it run without asking? [Permissions, sandboxing and containment](concepts/sandboxing-and-permissions.md).

**When something goes wrong**

- The agent picks the wrong tool, or misuses one. [Tool design](concepts/tool-design.md).
- Quality drops in long sessions. [Context engineering](concepts/context-engineering.md).
- Quality changed after launch. [Running agents in production](concepts/production-operations.md).

## Concepts

One page per idea: definition, what to do, where sources disagree.

**The stack**

- [Harness](concepts/harness.md) — what it is, its parts, the four layers, and whether it still matters. *Contested.*
- [Context layer](concepts/context-layer.md) — the configuration you own: instructions, skills, MCP servers, memory.
- [Agents and workflows](concepts/agents-and-workflows.md) — single call, workflow or agent, and the standard patterns.

**Configuring an agent**

- [Instruction files](concepts/instruction-files.md) — `AGENTS.md` and `CLAUDE.md`: keep short, use as an index, one source of truth.
- [Skills](concepts/skills.md) — procedures loaded on demand, how to write and prune them.
- [MCP](concepts/mcp.md) — connecting outside tools and data, what it costs in context, security.
- [Tool design](concepts/tool-design.md) — writing tools for a model: shape, inputs, outputs, edits, large tool sets.
- [Memory](concepts/memory.md) — layers, dreaming, when and where to write, risks.

**Information**

- [Context engineering](concepts/context-engineering.md) — context as a budget, compaction, notes, subagents.
- [Retrieval](concepts/retrieval.md) — cached prompt, hybrid search, agent-driven search, compiled wiki.
- [LLM wiki](concepts/llm-wiki.md) — the pattern this repository follows, and its limits.

**Scale**

- [Multi-agent systems](concepts/multi-agent-systems.md) — when several agents pay off, delegation, coordination, risks.
- [Long-running agents](concepts/long-running-agents.md) — state on disk, evaluators, scaffolding that expires, cost.
- [Running agents in production](concepts/production-operations.md) — regressions, deploys, infrastructure at agent volume.

**Quality**

- [Verification](concepts/verification.md) — evidence as the condition for done, tests that are hard to fool, checks as a system.
- [Evals](concepts/evals.md) — vocabulary, graders, how to start, behavioural evals.
- [Trusting eval numbers](concepts/eval-validity.md) — scaffold, infrastructure, leaks, saturation, statistics.
- [Compounding](concepts/compounding.md) — turning corrections into checks, rules and skills, and pruning them.

**Safety and people**

- [Permissions, sandboxing and containment](concepts/sandboxing-and-permissions.md) — boundary first, gate second, untrusted content.
- [Human judgment and oversight](concepts/human-judgment.md) — what stays with the person, and how to keep it.
